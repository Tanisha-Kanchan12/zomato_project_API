# 🍽️ Zomato Restaurant Analysis

A data analysis project based on the **Zomato restaurant dataset** and **Zomato API**. This project focuses on restaurant trends, cuisine analysis, ratings, pricing, and customer behavior using Python data analysis libraries.

---

## 📌 Project Overview

The project is divided into two parts:

### 🔹 Zomato API Analysis
- Fetch cuisine IDs
- Find top-rated restaurants
- Get restaurant reviews
- Distance-based restaurant search

### 🔹 Dataset Analysis
- Delhi-NCR vs Rest of India comparison
- Cuisine distribution analysis
- Ratings vs Votes analysis
- Price range analysis
- Top restaurant chains & localities

## 📌 Key Insights

- 🏙️ **Delhi-NCR** dominates the dataset
- 🍛 **North Indian & Chinese** cuisines are most common
- ⭐ Restaurants with **more votes** usually have **better ratings**
- 💰 **Mid to premium** restaurants tend to receive higher ratings
